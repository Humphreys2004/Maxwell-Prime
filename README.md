# MaxwellPrime Website

Responsive static landing page.

Before publishing:
- Replace the email and WhatsApp placeholders with public business contacts.
- Review the copy for accuracy.
- Optionally add the original approved logo.

Free GitHub Pages deployment:
1. Create a public repository (e.g. `maxwellprime-site`).
2. Upload `index.html` to the repository root.
3. Repository Settings → Pages → Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the URL shown by GitHub Pages.
